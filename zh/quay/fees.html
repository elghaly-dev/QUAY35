QUAY · 费用审查

优先费与小费配置审查

读取您的公开交易签名，将当前优先费/小费设置与交易实际支付及上链情况对比。

完整 brief 后 48 小时内交付一页书面报告。仅为建议——不改动配置、钱包或交易。

您需提供

均为公开数据。请勿发送链上或浏览器中不可见的内容。

  • 最多 200 条交易签名 — 仅签名。不要私钥、助记词或带 token 的 RPC。
  • 当前优先费设置
  • 当前小费设置
  • 您使用的 venue 或 aggregator

我们不会索取、展示或接受 API key、含 token 的 RPC 或私钥。

您将获得

完整 brief 后 48 小时内一页报告：

  • 当前设置实际上链分位
  • 目标分位及理由
  • 何时提高及触发条件
  • 多付之处及每笔上链浪费量
  • 无法从签名确定的内容，明确列出

签名无法读取的字段，报告写 UNKNOWN——不猜测。

仅凭签名无法告知的内容

签名显示提交与上链，不能反映运营全貌。至少看不到：

  • 成交（fills） — 上链交易是否达到预期成交结果
  • 您的策略 — 每次发送背后的意图、 sizing 与 timing 规则
  • RPC 延迟 — 节点/提供商传播交易所用时间
  • 某笔交易失败原因 若失败未上链（模拟拒绝、丢包、客户端取消）

无法从签名推导的内容在报告中标记 UNKNOWN。不填补空白。
